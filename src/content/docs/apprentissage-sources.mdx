## Méthode de mise à jour éditoriale

1. Mettre à jour la date de vérification dans les pages concernées.
2. Consulter les release notes et la documentation du produit, pas seulement une table de correspondances.
3. Marquer clairement GA, Preview, Pre-GA, dépréciation et disponibilité régionale.
4. Exécuter `npm run check`, `npm test`, `npm run check:links`, `npm run build` puis les tests navigateur.
5. Consigner dans le changelog la source, l’effet architectural et les sections modifiées.
